Project Graph PG1.3 / Windows x64
启动修复版 1.3.1：修复正式打包时涂鸦类先于父类初始化导致无窗口的问题；保留全部功能和原设置。

在 PG1.2 累计功能上新增：
- Ctrl+C 可选择复制节点或复制文本；同/跨文件粘贴以整个范围中心对齐鼠标。
- 右键文件标签可“合并文件分栏”，保留原文件和未保存内容。
- 支持截图、浏览器图片和资源管理器图片文件粘贴，沿用原图片节点与缩放操作。
- 右侧涂鸦/容器面板：长方形、圆形、名称、四角/数值调整、固定边界及解除约束。
- 空白画布 Ctrl+滚轮以鼠标为中心缩放，分栏与界面缩放下同样准确。
- 自由/直线彩色涂鸦，可调颜色、不透明度和直线宽度。
- 可调大小的局部橡皮：图片和涂鸦局部擦除，节点整块删除；支持撤销重做和保存恢复。
- 44 像素紧凑图标栏，顺序为橡皮、参数、容器、涂鸦、直线、长方形、圆形；原快捷设置入口保留。
- 容器/涂鸦可反复点击旧边框调整，点击其他位置自动固定；按住边框可整体拖动，容器内节点随动。
- 双击边框直接编辑或清空标题；默认无标题。
- 绘图快捷键可在“设置 → 快捷键 → 涂鸦”中修改：ER 橡皮、KK 容器、SQ 长方形、CY 圆形、ST 直线（均依次按键）。
- 原 ERR 功能保留；ER 与 ERR 同时可用时稍等约 350 毫秒判定。
- 按住 A 再按 I 唤起原 AI 面板，可在快捷键设置中修改；输入文本时不触发。

保留原 AI、查找替换、关联高亮、实验树布局、快捷键及其他设置。
程序显示名为 Project Graph PG1.3，保留现有内部程序标识以继承设置与登录。
这是 Windows 安装包；没有 macOS/iPhone 构建。
安装前保存项目并关闭正在运行的 Project Graph PG1.1/PG1.2。
容器放不下内容时会拒绝并提示扩大，不自动改变边界；不支持固定容器作为另一固定容器的内部成员。
