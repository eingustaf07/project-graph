Project Graph PG1.4 / Windows x64

在 PG1.3 1.3.1 全功能版本上增量开发：
- Ctrl+C 立即复制节点，保留连接、样式与布局，不再弹出复制方式选择框。
- 按住 Ctrl，在350毫秒内连按两次 C，复制选中节点的纯文本。
- 两项均可在“设置 → 快捷键 → 基础”中修改，名称分别为“复制节点”和“复制文本”。
- 长按 C 的自动重复不会误触发复制文本；文本输入框保留原有正常复制。
- 慢图片复制不会覆盖后来请求的纯文本；立即粘贴会等待本次复制完成，跨文件同样有效。
- 保留 PG1.3 全部功能、原有其他快捷键、基础设置和登录配置。
- 新增“设置 → 个性化 → 音效 → 音效音量（%）”滑动条，范围 0–100，默认 100；0 为静音。仅控制 PG 音效，实时生效并自动保存。
- 修复自定义构建缺少云服务地址时，鸣谢名单无法加载、扩展市场弹出 undefined 路径错误、PG 账户登录入口被禁用的问题。默认连接官方服务；保留自定义服务地址，遥测开关不因此开启。
- 鸣谢页增加返回数据校验与明确的失败重试提示；扩展市场两个入口均使用有效地址。
- 默认保留缩小画布后的节点文字及链接标题、地址，不再因字号低于阈值而自动隐藏。入口：“设置 → 性能 → 渲染 → 缩小时保留节点文字”。保留原阈值和整数对齐设置；小于一像素时避免把字号取整成零。
