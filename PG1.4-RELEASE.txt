Project Graph PG1.4 / Windows x64

在 PG1.3 1.3.1 全功能版本上增量开发：
- Ctrl+C 立即复制节点，保留连接、样式与布局，不再弹出复制方式选择框。
- 按住 Ctrl，在350毫秒内连按两次 C，复制选中节点的纯文本。
- 两项均可在“设置 → 快捷键 → 基础”中修改，名称分别为“复制节点”和“复制文本”。
- 长按 C 的自动重复不会误触发复制文本；文本输入框保留原有正常复制。
- 慢图片复制不会覆盖后来请求的纯文本；立即粘贴会等待本次复制完成，跨文件同样有效。
- 保留 PG1.3 全部功能、原有其他快捷键、基础设置和登录配置。
- 新增“设置 → 个性化 → 音效 → 音效音量（%）”滑动条，范围 0–100，默认 100；0 为静音。仅控制 PG 音效，实时生效并自动保存。
- 修复自定义构建缺少云服务地址时，鸣谢名单无法加载、扩展市场弹出 undefined 路径错误、PG 账户登录入口被禁用的问题。默认连接官方服务；保留自定义服务地址，遥测开关不因此开启。
- 鸣谢页增加返回数据校验与明确的失败重试提示；扩展市场两个入口均使用有效地址。
- 默认保留缩小画布后的节点文字及链接标题、地址，不再因字号低于阈值而自动隐藏。入口：“设置 → 性能 → 渲染 → 缩小时保留节点文字”。保留原阈值和整数对齐设置；小于一像素时避免把字号取整成零。
- 修复普通文字节点在碰撞与自动对齐同时开启时的重叠问题：中心完全重合不再触发零位移递归，绝对定位、文字增高、手动宽度变化和普通新建节点均补上碰撞处理。保留原自动对齐、碰撞开关和其他设置。

本次累计新增与修复（入口名称可在设置搜索中查找）：
1. Ctrl+C 复制节点，按住 Ctrl 连按两次 C 复制纯文本。设置 → 快捷键 → 基础。
2. Ctrl+X 剪切节点，Ctrl+V 在鼠标位置粘贴，支持跨文档。
3. 音效音量滑动条与每项音效独立开关。设置 → 个性化 → 音效。
4. 成功双击创建节点、创建涂鸦/容器及快捷键删除新增柔和音效。
5. 音效预加载与缓存，丢弃过期反馈以减少延迟。
6. 绘图工具栏仅在 BB 画笔模式生效，默认底部，拖动把手可停靠上下左右。取消旧鼠标模式图形栏。
7. 实验性跨文件节点连接。设置 → 视觉 → 实验性功能 → 跨文件节点连接。启用后使用画布右上方跨文件连接入口。
8. 选中边反向功能仍可在“设置 → 快捷键”中搜索“反向”配置；当前源码没有新增单键 R/G 转换选中边的绑定，不能将此项计入已完成新功能。
9. Tab+R 让下一次 NN 的新连线指向原节点，Tab+G 让下一次 NN 产生无向边。仅消费一次。
10. A+I 打开/关闭 AI 面板。
11. ZZ、BB、CC 三种模式均可在空白处双击创建节点，遵循现有双击行为设置。
12. 容器嵌套收纳与整体移动，外层移动带动内层容器和节点。
13. 容器自动扩张。设置 → 控制 → 分组框 → 容器自动扩张，默认关闭。
14. 按 N 拖入/移出容器。设置 → 控制 → 分组框 → 按 N 拖入或移出容器，默认关闭，全局适用。
15. 修复命名后调整容器大小、重复修改涂鸦标题、缩放时容器标题消失。
16. 修复连续右键连接误判自环，以及普通文字节点碰撞与自动对齐同时开启时的重叠。
17. 修复 NN 在双向弧线结构中递归卡顿，并保护生成后的自动编辑请求。

实验性跨文件连接限制：同一 PG 窗口内已保存的本地文件，支持拆分及应用内浮动。目标文件改名或移动后需重新连接，单画布导出不包含跨文件连接。
验证边界：自动化检查和打包启动检查不等于所有鼠标、音效听感、云账户真实登录与长时间使用均已人工验收。
