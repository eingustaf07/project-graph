# Retro Pixel UI

This is Gustaf Ein's existing combined UI font, reused unchanged for Project Graph E.
The Latin glyphs originate from Departure Mono 1.500; the CJK glyphs originate from
Fusion Pixel 12px Mono zh-Hans. Both sources use the SIL Open Font License 1.1.
Original license and upstream attribution files are included alongside the font.

Family: Retro Pixel UI. Style: Regular. File: RetroPixelUI-Regular.ttf.
SHA256: 5F90DAECA76737056CB854E33B39B19BB795A37B3CAE2B1E408043D22809D123.

The font is a local application asset. No download from an external font service,
system font replacement module, or manual per-window style injection is required.
