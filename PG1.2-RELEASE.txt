Project Graph PG1.2 / 1.2.0

累计版本包含：
- 已有 ChatGPT 登录与原自定义 API 模式。
- 测量真实节点尺寸的 AI 树生成与布局保护。
- 查找替换和批量撤销。
- 关联节点高亮及直接/间接相连范围设置。
- 智能规整树形布局（设置 → 视觉 → 实验性功能，默认关闭）。

兼容说明：
产品、窗口和安装包显示为 PG1.2，软件版本 1.2.0。
沿用 eingustaf07.project-graph-pg11 内部标识、原配置目录及 project-graph-pg11.exe 文件名，
避免更换数据命名空间导致快捷键、设置、AI 登录及现有连接方式丢失。
这些内部兼容名称不代表软件仍是 1.1；以窗口、文件产品版本及安装包版本为准。
PG1.0 独立安装及配置不变；PG1.1 旧安装目录和本地备份保留。
新版本默认安装目录为用户 LocalAppData 下的 Project Graph PG1.2。
PG1.1 与 PG1.2 使用相同配置，请先保存并关闭旧版，再运行新版，避免同时写配置。
本包未更改现有快捷键、节点文件格式、旧 API 接口或窗口启动方式。

实验布局：
启用后选中根节点或中间节点，按 Ctrl+Alt+L，也可用右键菜单。
模式可保留原方向或统一四方向，参数 64/24/40 可调，支持一次撤销。
环路、多父、分组框内、非矩形节点、分支内部转弯等会安全拒绝，详见 SMART_TREE_ARRANGE_REPORT.txt。

安装前保存项目并关闭旧 PG，使用默认安装目录。
已有设置和 ChatGPT 登录会由原配置目录继续读取，不需要手动重设。
没有改变 .prg 默认打开方式；如 Windows 仍指向旧版，可通过“打开方式”选择 PG1.2 安装目录中的程序。
